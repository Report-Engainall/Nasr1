# P1 — مركز المورد المالي ومصدر كمية أمر الشراء

- المستودع: `Report-Engainall/Nasr1`
- نقطة الأساس عند نقل التنفيذ: `860d6e47705f79676c7e1ed2697075a9644048f4`
- الفرع النهائي: `main`

## التنفيذ

- تركيب مركز مالي بتحميل كسول داخل دليل الموردين، يعيد استخدام مساحات المدفوعات والفواتير ومراجعة الفروقات وكشف حساب المورد الموجودة.
- إظهار التبويبات للأدوار `admin` و`manager` و`accountant` فقط؛ المستخدم غير المالي لا يطلب دليل الأستاذ ولا يرى أدوات التسوية.
- قراءة دليل الحسابات من RPC `fetch_general_ledger` نفسه المستخدم في دفتر الأستاذ، مع تحقق حقول الحساب ورفض الرد غير الصالح والمكرر.
- إظهار الكمية المطلوبة في إدخال الفاتورة ومراجعتها عبر معرّف بند أمر الشراء الثابت فقط، مع إعادة استخدام أوامر الشراء التي حمّلتها صفحة المشتريات بالفعل.
- القراءة البديلة لأوامر الشراء محصورة بالمدير/مدير النظام. لا يجرى تخمين للكمية ولا تعرض كمية صفرية عند غياب المصدر؛ الحالة تكون `غير متاح`.
- إبطال النتائج المتأخرة لدليل الحسابات عند تغير هوية الجلسة لمنع بقاء إسقاط الحساب السابق.

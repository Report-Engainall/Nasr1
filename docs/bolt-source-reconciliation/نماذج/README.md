## قواعد الاستخدام
1. لا تحفظ `.env` أو أسرارًا أو بيانات عملاء أو نسخ قواعد بيانات.
2. لا تنفذ Migration من نموذج قبل مراجعة مخطط Nasr1 وRLS/RPC والصلاحيات والتدقيق.
3. لا تنسخ ميزة موجودة أو تنشئ خدمة ثانية؛ راجع التقرير وسجل التكامل.
4. لا تستبدل ملفات READY_TO_REUSE دون تحديث provenance والبصمات والقرار.
5. وجود صورة أو ملف مصدر ليس إثبات اختبار أو نشر.

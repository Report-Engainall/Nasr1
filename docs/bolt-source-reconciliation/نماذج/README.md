# مجلد النماذج والصور

هذا المجلد مخصص لرفع الصور واللقطات المرجعية المرتبطة بمراجعة مصادر Bolt ومطابقة الواجهات والوظائف في مشروع Nasr1.

## طريقة رفع الصور

1. افتح هذا المجلد في GitHub.
2. اختر **Add file** ثم **Upload files**.
3. اسحب الصور إلى الصفحة أو اخترها من جهازك.
4. اكتب وصفًا موجزًا يوضح محتوى الصور، ثم احفظ التغييرات (**Commit changes**).

يفضّل استخدام أسماء ملفات واضحة، مثل `product-list.png` أو `admin-pricing-screen.png`، مع تجنّب وضع كلمات المرور أو المفاتيح أو أي بيانات شخصية حساسة داخل الصور.

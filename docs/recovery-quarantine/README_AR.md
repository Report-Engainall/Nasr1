# ملفات SQL المسترجعة — منطقة حجر

الملفات في هذا المسار أدلة مراجعة فقط، وليست migrations فعالة. لا تنقلها إلى supabase/migrations ولا تطبقها قبل مراجعة المخطط الحقيقي وسياسات RLS ومنح الصلاحيات والدوال، والاختبار في قاعدة معزولة. ملفا role/password محفوظان في سجل الجرد بالبصمة والحجم فقط ولم ينسخ محتواهما إلى هذا الفرع لحين المراجعة الأمنية.
